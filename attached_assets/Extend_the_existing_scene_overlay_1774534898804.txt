Extend the existing scene overlay editor to support text overlays as a first-class overlay type alongside image overlays. Text overlays are composited in Remotion at render time — not baked into video clips.
New overlay type: Add type: 'text' | 'image' to the SceneOverlayItem interface in shared/video-types.ts. Text overlays add these additional fields:

// Additional fields for text overlays
text: string;
textType: 'headline' | 'script-accent' | 'body' | 'bullet-list' | 'stat-callout' | 'lower-third' | 'cta-badge' | 'caption-bar';
fontFamily: string;
fontWeight: 300 | 400 | 500 | 700 | 900;
fontSize: number; // percentage of canvas height
color: string; // hex
backgroundColor?: string; // hex with alpha, for badge/bar types
textAlign: 'left' | 'center' | 'right'; // text alignment WITHIN the block only — canvas position is controlled by x/y via drag-and-drop
opacity: number;
bulletPoints?: string[]; // for bullet-list type
entranceAnimation: 'fade' | 'rise' | 'drop' | 'wipe-left' | 'wipe-right' | 'scale-pop' | 'typewriter' | 'blur-in' | 'none';
emphasisAnimation: 'pulse' | 'float' | 'shimmer' | 'none';
exitAnimation: 'fade' | 'slide-out' | 'scale-down' | 'none';
startTime: number; // seconds from scene start
duration: number; // seconds visible, 0 = full scene
bulletDelay: number; // seconds between bullet entrances, default 0.4
snapPosition?: 'top-left' | 'top-center' | 'top-right' | 'middle-left' | 'center' | 'middle-right' | 'bottom-left' | 'bottom-center' | 'bottom-right' | null; // last snapped position — null means free-positioned by drag

Text overlays must use identical drag-and-drop free positioning as image overlays — click and drag to place anywhere on canvas, corner handles to resize with proportional font scaling, position stored as percentage-based X/Y coordinates.
The text alignment control (left/center/right) applies only to text alignment WITHIN the text block itself — not to canvas position. Canvas position is always controlled by drag-and-drop.
