Plan #30 — Studio Polish Project Type
What & Why:
Add a fourth project creation type called "Studio Polish" to the /projects/new page. This type allows users to upload existing videos or images (from their device or from their NeuralCut Asset Library), then apply the full Render Configuration pipeline — intros, outros, captions, voiceover, background music, sound design, film treatment, and transitions — exactly as AI-Generated Script and Custom Script projects do. The primary use case is enhancing manufacturer videos, raw footage, or externally sourced content with professional NeuralCut production finishing.

Task 3 — Studio Polish project data model:
Add projectType: 'studio-polish' to the existing project type enum in shared/video-types.ts and shared/schema.ts.
For Studio Polish projects, the scenes array is built from the uploaded files rather than AI-generated script. Each uploaded file becomes one scene:
typescript// For each uploaded file, create a scene:
{
  sceneId: generateId(),
  sceneNumber: index + 1,
  narration: '', // empty — no narration for uploaded content
  visualDirection: '', // empty — video is the source
  duration: fileDuration || 5, // extracted from video metadata
  sourceVideoUrl: uploadedFileS3Url, // the uploaded file URL
  sourceType: 'upload', // vs 'ai-generated'
  microScenes: [{
    id: generateId(),
    narration: '',
    visualDirection: '',
    duration: fileDuration || 5,
    videoUrl: uploadedFileS3Url, // the source video IS the micro-scene video
    status: 'ready', // already has video — no generation needed
    pipelineStage: undefined
  }]
}
This means Studio Polish scenes skip AI video generation entirely — the uploaded files are treated as already-generated micro-scene videos. The FFmpeg assembly and Remotion render pipeline can then apply all the finishing (intro, outro, captions, voiceover, music, film treatment) exactly as it does for AI-generated projects.

Task 4 — File upload infrastructure:
Create server/services/studio-polish-upload-service.ts:

Accept multipart form upload or S3 asset URL reference
For video uploads: extract duration and generate thumbnail using FFmpeg (ffprobe for duration, single frame extract for thumbnail)
Upload source file to S3 under /studio-polish/{userId}/{projectId}/source/ path
Return: { s3Url, thumbnailUrl, duration, fileType, fileName, fileSize }
For image uploads: no duration extraction needed, set duration to 5s default (configurable)
Store uploaded assets in mediaAssets table with type: 'studio-polish-source'

Add upload endpoint: POST /api/studio-polish/upload

Task 5 — Project detail page behavior for Studio Polish:
When a project has projectType: 'studio-polish', the project detail page should:

Show uploaded source videos as scene cards — same scene card UI as AI-generated projects
Scene cards show the source video player (the uploaded file) instead of an AI-generated clip
Hide the "Generate Script" and "Generate All Videos" buttons — these don't apply
Show a "Reorder Scenes" button — lets users drag scenes to reorder if they uploaded multiple files
Scene overlays, text overlays, and per-scene overlay editor work identically to AI-generated projects
The Render Configuration panel appears and functions identically — full access to intro, outro, captions, voiceover, music, sound design, film treatment, transitions
"Start Render" button triggers the Remotion render pipeline with the uploaded source videos as the scene video inputs
Show a "Add More Clips" button to upload additional source files and add them as new scenes after project creation


Task 6 — Render pipeline compatibility:
Verify that the existing Remotion render pipeline (remotion/UniversalVideoComposition.tsx) correctly handles scenes where microScenes[0].videoUrl points to an uploaded S3 file rather than an AI-generated clip. This should work without changes since the composition already reads videoUrl from micro-scenes — but explicitly test that:

An uploaded MP4 with different codec/container than Kling-generated clips renders correctly
The intro/outro/captions/music/voiceover all composite correctly over uploaded source video
Film treatment (color grade, grain, vignette) applies to uploaded source video

If FFmpeg pre-normalization (codec standardization, resolution normalization) is needed for uploaded files before Remotion receives them, add a normalization step in the FFmpeg assembly service that runs on Studio Polish source videos before assembly.
